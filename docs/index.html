Fergie

Fergie is a private Discord community assistant operated by fergielicious.

About Fergie

Fergie provides entertainment, music, and community features for a small private Discord community.

Pinterest Integration

Fergie uses the Pinterest API with authorization from the connected Pinterest account owner. The integration reads Pins and Boards belonging to the authorized account so that selected fashion Pins from an account-owned board can be periodically shared in a designated private Discord channel.

The Pinterest integration is read-only for this feature. Fergie does not create, modify, or delete Pinterest Pins or Boards and is not offered as a Pinterest integration for general users.
